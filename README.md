# LiklikDrama Website 🎭

LiklikDrama is a premium cultural entertainment platform in Papua New Guinea. We empower local shops, creators, and storytellers through high-quality video promotion, interactive live selling, and authentic community storytelling.

## 🌟 Core Features

- **Video Promotion:** Elevate your local business with professional, engaging video marketing targeting real customers.
- **Live Selling:** Connect instantly with buyers in POM through our seamless live streaming platform.
- **Community Storytelling:** Submit, read, and share authentic Tok Pisin stories through our interactive web portal.

## 🛠 Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (Custom Properties, Glassmorphism, CSS Grid/Flexbox), and JavaScript (ES6+).
- **Backend:** Python (Flask) with MySQL for secure story submission and management.
- **Interactivity:** Custom cursors, scroll progress indicators, scroll-triggered fade-in animations, and interactive buttons with ripple effects.

## 🚀 Quick Setup

### Frontend Development
1. Clone this repository.
2. Open the project folder in your terminal.
3. Start a local server:
   ```bash
   python -m http.server 8000
   ```
4. Navigate to `http://localhost:8000` in your web browser.

### Backend Setup
For database initialization, API configuration, and Flask server setup, please refer to the detailed [Backend Setup Guide](./BACKEND_SETUP.md).

## 📂 Project Structure

- `index.html`, `about.html`, `services.html`, etc. - Main web pages.
- `main.css` - Global stylesheet with custom variables and animations.
- `main.js` - Core functionality, UI interactions, and form submissions.
- `access-gate.js` - Secure access mechanism for exclusive content.
